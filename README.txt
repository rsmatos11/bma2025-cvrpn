This folder contains the source codes, problem instances, and computational results related to the manuscript:

"Solving the capacitated vehicle routing problem with polygonal neighborhoods 
using a metaheuristic enhanced with block coordinate descent" 
by Ernesto G. Birgin and Rogerio S. Matos.

This repository provides the complete set of instances, computational results,
and algorithmic implementations presented in the study.

STRUCTURE
=========

The directory is organized as follows:

- Codes     : source codes of the proposed method and of the CPLEX models.
- Instances : small-, medium-, and large-scale instances, and the instances
              used in the calibration.
- Solutions : solutions found by the proposed method.
- index.html: table with links to the instances and solutions.
